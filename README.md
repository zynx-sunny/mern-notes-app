# MERN Notes App

A full-stack notes application built using the MERN stack.

## Features

- User Authentication (JWT)
- Create Notes
- Edit Notes
- Delete Notes
- Protected Routes

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
